# Photo credits

The photos in this folder are from The Chapel of Faith, FUTA's own public Facebook page
(https://www.facebook.com/thechapeloffaithfuta/photos). The church has said its pictures may be
used on this website. Each file was cropped to remove text, a caption band or a watermark, then
resized and compressed for the web.
